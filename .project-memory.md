### Correções Implementadas

#### 1. Nome da Instituição na Tabela de Solicitações ✅
- **Problema**: Nomes vazios na tabela "Solicitações de Registo de Instituições"
- **Causa**: Campo `nome` não estava a ser preenchido corretamente, dados reais estão em `nome_completo` ou `fullName`
- **Solução**: Fallback chain para exibir nome: `row.nome || row.nome_completo || pack?.nomeCompleto || pack?.sigla || row.bi_numero`
- **Commit**: e12b1c0
- **Status**: ✅ Funcionando

#### 2. Popup de Eliminar - Posicionamento ✅
- **Problema**: Popup aparecia fora da viewport, utilizador tinha que rolar para encontrá-lo
- **Causa**: Posicionamento com Tailwind classes não estava a funcionar corretamente
- **Solução**: 
  - Usar flexbox para centrar o popup no centro do viewport
  - Z-index elevado (99999) para garantir sobreposição
  - Estrutura com div wrapper para posicionamento correto
  - `onClick stopPropagation` para evitar fechamento acidental
- **Commits**: b2e004b, f723884
- **Status**: ✅ Funcionando

#### 3. Botão "Eliminar Definitivamente" - Eliminação Completa ✅
- **Problema**: Botão apenas fechava o popup sem eliminar o registo
- **Causa**: 
  - RPC `cda_admin_alfa_eliminar_registo` falhava (admin demo não tem sessão Supabase Auth)
  - Fallback `eliminarInstituicaoCloud` também falhava (requer token de sessão)
  - Popup fechava automaticamente via `.finally()` mesmo em caso de erro
- **Solução**:
  - Criar endpoint `/api/admin-eliminar-instituicao` com service role key (funciona sem sessão)
  - Implementar fallback automático: RPC -> endpoint admin
  - Eliminação completa em cascata:
    * Contas Auth dos agentes
    * Avatares do Storage (fotos_perfil)
    * Perfis (profiles)
    * Mensagens e histórico de estados
    * Notificações
    * Sondagens
    * Protocolos digitais
    * Solicitação de registo
    * Vestígios adicionais (vídeo-sessões, contactos, pedidos, documentos)
  - Adicionar feedback visual de erros no popup
  - Popup só fecha após sucesso (não fecha em caso de erro)
  - Mensagens de erro claras para o utilizador
- **Commit**: 5af0e55
- **Status**: ✅ Funcionando
